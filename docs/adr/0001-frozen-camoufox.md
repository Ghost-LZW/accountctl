# 只支持 Camoufox，保存最终配置而非每次生成启动选项

用户明确要求账号间指纹不同、同一账号指纹稳定，且只支持 Camoufox。因此不抽象可切换浏览器引擎，不接入 Chrome。

Camoufox 0.4.11 的 `launch_options` 即使收到相同 BrowserForge 指纹也会随机选择字体种子、Canvas、WebGL 等参数。首次调用后保存其完整生效配置和 Firefox prefs；恢复时通过 Playwright 使用 Camoufox 二进制直接启动持久化上下文，避免再次调用生成器。

这依赖 Camoufox 内部配置约定，因此绑定库版本、浏览器版本和二进制 SHA-256，任何变更先拒绝启动。GeoIP 在首次生成时使用账号代理查询并固化，后续不动态重采样；新账号默认关闭 WebRTC。代理/IP 可变，但不宣称网络身份稳定。运行时升级需要显式规划迁移，不能以修复为由自动重生成已登录账号指纹。

旧脚本没有保存的随机参数无法追溯；旧 profile 保留原始输入及登录目录，首次接入时固化缺失参数，不声称完全复原旧网站观测值。

用户进一步指定 `claude02` 的原代理、GeoIP 与 1280×800 启动行为必须保留，因此接入命令启用 legacy 兼容设置，保留原窗口覆盖、WebRTC、默认扩展，并在运行时读取旧 meta.json 的代理。相比强制秘密迁移，这保留了现有可运行环境且不复制密码；未来可显式改为 proxy_ref，但不能静默关闭代理/GeoIP。
